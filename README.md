# Blocky Lovers
Blocky Lovers is a Minecraft mod for Fabric 26.3, designed to enable wholesome interactions between players.

## Still In Development
Features:
- Marriage contracts between players
- Heart points that give buffs at certain levels
- Tasks for partners to grant heart points
- Animations??
